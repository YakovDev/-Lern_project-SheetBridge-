# 🌉 SheetBridge

**Turn spreadsheets into structured data**  
_From Excel rows to JSON flows — and back to smart reports_


---

## О проекте

**SheetBridge** — это ETL-приложение для анализа банковских транзакций из Excel-файлов. Оно читает выгрузки банков, нормализует данные, преобразует их в структурированные **JSON-схемы** для веб-интерфейсов и одновременно генерирует кастомизированные **Excel-отчёты** с группировками и статистикой. Сервис автоматизирует рутинную обработку «сырых» таблиц, превращая их в готовые дашборды и аналитические сводки.

### Ключевые возможности

- 🔄 **Импорт и нормализация** — загружает Excel-файлы (`xlsx`, `xls`), приводит колонки к единому стандарту (дата, сумма, контрагент, категория).
- ⚙️ **Гибкая конфигурация** — маппинг полей задаётся через конфигурационные файлы (поддерживаются регулярные выражения и пользовательские правила).
- 📊 **Генерация JSON для веб-страниц** — создаёт иерархические JSON-объекты, готовые для отрисовки графиков и таблиц.
- 📑 **Формирование кастомных Excel-отчётов** — строит итоговые таблицы с агрегацией по дням, категориям, контрагентам; поддерживает формулы и условное форматирование.
- 🧩 **Расширяемость** — модульная архитектура позволяет добавлять новые источники данных, трансформации и форматы вывода.
- 🚀 **Готов к интеграции** — может работать как CLI-утилита или как REST API (опционально).
