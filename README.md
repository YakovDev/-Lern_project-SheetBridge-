## 📖 О проекте

**SheetBridge** — это ETL-приложение для анализа банковских транзакций из Excel-файлов. Оно читает выгрузки банков, нормализует данные, преобразует их в структурированные **JSON-схемы** для веб-интерфейсов и одновременно генерирует кастомизированные **Excel-отчёты** с группировками и статистикой. Сервис автоматизирует рутинную обработку «сырых» таблиц, превращая их в готовые дашборды и аналитические сводки.

### 🚀 Ключевые возможности

- 🔄 **Импорт и нормализация** — загружает Excel-файлы (`xlsx`, `xls`), приводит колонки к единому стандарту, обрабатывает пропуски и аномалии.
- 📊 **Генерация JSON для веб-страниц** — создаёт иерархические JSON-объекты (статистика по картам, топ-транзакций, доходы/расходы), готовые для отрисовки графиков и таблиц.
- 🔎 **Умный поиск** — фильтрация транзакций по ключевым словам, регулярным выражениям (поиск мобильных номеров и переводов физлицам).
- 🌐 **Интеграция с API** — получает актуальные курсы валют и цены на акции S&P 500 в реальном времени.
- 📑 **Формирование Excel-отчётов** — строит итоговые таблицы с агрегацией по дням, категориям и рабочим/выходным дням с помощью `pandas` и кастомных декораторов.
- ⚙️ **Гибкая конфигурация** — маппинг полей и списки валют/акций задаются через пользовательские конфигурационные файлы.
- 📝 **Логирование** — прозрачное отслеживание всех этапов работы с записью в консоль и файл.
- 🧪 **Покрытие тестами** — модульные тесты с использованием `pytest` и `requests-mock`.

## ⚙️ Установка

### Требования
- Python 3.13+
- Poetry (рекомендуется последняя версия)

### Шаги

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/yourusername/sheetbridge.git
   cd sheetbridge
   ```

2. **Установите зависимости**
   ```bash
   poetry install
   ```

3. **Настройте конфигурацию**
   Создайте файл `configs/user_settings.json` для указания валют и акций, которые нужно отслеживать:
   ```json
   {
     "user_currencies": ["USD", "EUR"],
     "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
   }
   ```

4. **Подготовьте данные**
   Поместите ваш Excel-файл с транзакциями в папку `data/input/` и назовите его `operations.xlsx`.

## 🚀 Использование (CLI)

Приложение управляется через командную строку с помощью фреймворка `argparse`. 

**1. Запуск на текущую дату (по умолчанию):**
```bash
poetry run python -m src.main
```

**2. Запуск на конкретную дату (формат: `YYYY-MM-DD HH:MM:SS`):**
```bash
poetry run python -m src.main --date "2021-12-31 23:59:59"
```

**3. Указание своих путей для сохранения результатов:**
```bash
poetry run python -m src.main --date "2021-12-31 23:59:59" --output-json "data/output/my_result.json" --output-excel "data/output/my_report.xlsx"
```

### 📁 Результаты работы
После успешного выполнения:
1. В консоль выводятся статусы с датой и временем (благодаря настроенному `logger`).
2. В файл `logs/sheetbridge.log` записывается полная история работы.
3. В папке `data/output/` появляются:
   - **JSON-файл** (содержит `main_page` и `events_page` для веб-интерфейса).
   - **Excel-отчёт** с аналитикой расходов.

## 🧪 Тестирование

Проект имеет **100% покрытие кода** модульными тестами. Все запросы к внешним API замоканы, поэтому тесты работают мгновенно и не зависят от интернета.

Для запуска тестов с проверкой покрытия:
```bash
poetry run pytest tests/ -v --cov=src --cov-report=term-missing
```
